Playwright
----------
Playwright is an open-source tool developed by Microsoft for automating web browser testing.
Apart from browser automation, Playwright also supports API testing for validating backend services.
It is mainly used for end-to-end testing of web applications.
Playwright was released in 2020.
It is an open-source Node.js library.

Real Browsers vs Rendering Engines 
---------------------------------

Chromium, firefox and webkit are rendering browser engines (Not real browsers).

Real browsers are developed using rendering engines:


•	Chromium engine is used in Google Chrome, Microsoft Edge, Brave and Opera.
•	Webkit engine is used in Safari.
•	Gecko engine is used in Firefox

------
Playwright installation
 npm init playwright@latest

check the version:
	npx playwright --version

to run the test:

	npx playwright test <file name>



headless mode --- default execution ( without opening browsers)

npx playwright test ./tests/mytest.spec.ts --headed
